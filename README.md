# Runvessa downloads

Official distribution repository for Runvessa, published by Cresdig. The application source repository remains private. This repository contains release materials only, not the application source.

Preview releases are evaluation builds, not promises that every hosting-provider route is complete. DirectAdmin and unverified public DNS/mail cutover routes remain gated.

The preview.6 Setup installer is being verified for release. No WinGet, Chocolatey or Microsoft Store listing is claimed until the respective submission has been accepted. Check release notes and SHA256 checksums before installing. The preview installer is unsigned.
